# 永恩 009 三主动槽技能契约

`dual_blader` 只使用三个真实主动槽：`skill=Q`、`skill2=W`、`ult=R`。第二主动槽是 W-only，不混入或展示 E 灵体逻辑。

## Q — 错玉切

- [x] Q 使用 `Q1 → Q2 → Q3` 三段状态。
- [x] Q1/Q2 只有命中才推进持续 360 tick 的命名层数；空放不叠层。
- [x] Q3 施法时消耗第二层，只执行一次无伤害 `RushTime` 和一条风道。
- [x] Q3 风道只结算一次 `25 + 80% AD` 物理伤害与一次 45 tick `Airborne`。

## W — 凛神斩 / Spirit Cleave

- [x] `skill2` 是固定30 tick动作、480 tick冷却、42000施法范围的方向技能，AI目标类型为 `EnemyWithoutTower`。
- [x] 五帧 `skill2_attack` 是站定双刀横斩；没有冲刺、追背、击飞、灵体、本体锚点、返回或位移。
- [x] 每次施放只生成一个 `36000×42000` 的 `LineRangeProjectile`，对 `EnemyWithoutTower` 中每个目标最多应用一次。
- [x] 同一命中载荷先调用 `lol_yone_w_collect_hit_native`，再结算一次 `50 + 90% AD` 伤害和命中特效/音效；伤害与护盾统计不会使用两套目标集合。
- [x] `lol_yone_w_begin_native` 在范围命中前清空本次账本；`lol_yone_w_settle_native` 在2 tick后拥有完整去重目标集，并只写入一个短时护盾档位。
- [x] 命中任意敌人（包括小兵或野怪）获得90 tick的 `50 + 20% AD` 基础护盾。
- [x] 命中一名英雄时护盾为 `100 + 40% AD`；第二至第五名英雄每名再增加 `25 + 10% AD`。标准五人敌方阵容全部计入，不存在旧版两英雄人工封顶。
- [x] 六个 `lol_yone_w_shield_tier_0..5` 数据分支互斥；匹配分支移除自身标记并只执行一次 `Shield`、一次护盾VFX和一次护盾音效。
- [x] 公开 Mod API 0.8 不能表达随攻速动态变化的动作与冷却，本版本明确使用固定30/480 tick近似。

## 状态隔离与退役逻辑

- [x] W账本不调用跨版本不安全的 `ModService`；最多保留128条，并以施法者 `EntityHandle`、player、team、position和最近的 `started_tick` 匹配。
- [x] 目标以 `target_id + EntityHandle` 去重；记录发生在伤害前，因此致死命中仍能获得护盾。
- [x] 当前技能数据、素材路径和发布清单不得包含 `YoneSoulUnbound`、`yone_spirit` 或 `yone_e_icon_source`；仅允许五个精确的 `lol_yone_e_*` 名称作为旧存档无行为兼容别名，不能恢复E逻辑。

## 战斗脸部与视觉合同

- [x] 全部54个可见战斗身体帧使用幂等的最终像素级RGB重绘，每帧恰好保留一对相邻深色眼眉像素。
- [x] 重绘前后画布尺寸、alpha字节、原生矩形、帧数、时长和脚底锚点完全一致；脸部局部不得残留近白模糊像素。
- [x] W使用独立的月牙、命中和护盾图集标签，Q/W/R三个图标互不复用。

## R — 封尘绝念斩

- [x] R 保留一次到达击飞、六次交替物理斩击与一次固定伤害灵魂回响。
- [x] 延迟点为 `8/16/24/32/40/48/60`，总运行时间落在96 tick动作窗口内。
