# 永恩 009 三主动槽技能契约

`dual_blader` 只使用三个真实主动槽：`skill=Q`、`skill2=W`、`ult=R`。第二主动槽是 W-only，不混入或展示 E 灵体逻辑。

> **存档前置条件：必须使用在 `0.10.5` 或更高版本中新建的存档验证本合同。** 旧 E 存档和 `0.10.4` 矩形 W 存档只通过无行为原生效果别名安全加载；它们内嵌的旧技能树不会被迁移成下面的 W。`0.10.9` 只修复人物显示路由，已有有效 `0.10.5` W 存档升级后不需要再次新建。

## Q — 错玉切

- [x] Q 使用 `Q1 → Q2 → Q3` 三段状态。
- [x] Q1/Q2 只有命中才推进持续 360 tick 的命名层数；空放不叠层。
- [x] Q3 施法时消耗第二层，只执行一次无伤害 `RushTime` 和一条风道。
- [x] Q3 风道只结算一次 `25 + 80% AD` 物理伤害与一次 45 tick `Airborne`。

## W — 凛神斩 / Spirit Cleave

- [x] `skill2` 是固定30 tick（0.5秒）动作、480 tick（8秒）冷却、42000施法范围的方向技能，AI目标类型为 `EnemyWithoutTower`。
- [x] 五帧 `skill2_attack` 是站定双刀横斩；没有冲刺、追背、击飞、灵体、本体锚点、返回或位移。
- [x] `lol_yone_w_cone_native` 在当前一次 `GameCtx` 内扫描前方完整 `80°`、最远 `42000` 的真实锥形；数据树不再生成 `36000×42000` 宽矩形 `LineRangeProjectile`。
- [x] 每个存活、可选中、非友方、非防御塔目标最多命中一次，并结算 `35 + 45% Attack + 6% 目标最大生命值` 物理伤害。
- [x] 伤害、是否命中任意敌人、命中英雄数量与护盾档位都来自同一次锥形扫描；没有第二命中体、英雄探针、延迟 settle 或进程级命中账本。
- [x] 命中任意敌人（包括小兵或野怪）获得90 tick的 `50 + 20% AD` 基础护盾。
- [x] 命中一名英雄时护盾为 `100 + 40% AD`；第二至第五名英雄每名再增加 `25 + 10% AD`。标准五人敌方阵容全部计入，不存在旧版两英雄人工封顶。
- [x] 六个 `lol_yone_w_shield_tier_0..5` 数据分支互斥：tier 0 表示只命中非英雄敌人，tier 1..5 表示命中对应数量的英雄；匹配分支移除自身标记并只执行一次 `Shield`、一次命中VFX、一次护盾VFX和一次命中/护盾音效。
- [x] 公开 Mod API 0.8 不能表达 W 专用、随攻速动态变化的动作与冷却，本版本明确披露固定0.5秒/8秒近似，不宣称实现官方攻速缩放。

## 状态隔离与退役逻辑

- [x] W没有 `static` / `OnceLock` / `Mutex` 全局 registry，也不使用 caster、player、team、position 或最近 tick 猜测归属；每次原生调用只读写传入的一个 `GameCtx`。
- [x] 目标先在当前调用的局部集合中完成锥形过滤和伤害参数采集，再逐个结算；最终只给同一施法者写入一个 `lol_yone_w_shield_tier_0..5` 标记。
- [x] 当前主动技能数据、素材路径和发布清单不得恢复 `YoneSoulUnbound`、`yone_spirit` 或 `yone_e_icon_source`。退役的 `lol_yone_e_*` 原生名与 `0.10.4` 矩形 W begin/collect/settle 名只允许注册为旧存档无行为兼容别名，不能执行旧 E、矩形攻击或账本逻辑。
- [x] 兼容别名仅防止读取旧存档时缺少原生效果导致 BP 后闪退；不会迁移存档内嵌行为树。新 W 只在 `0.10.5` 或更高版本中新建的存档中成立；升级到 `0.10.9` 不会要求有效 `0.10.5` W 存档重建。
